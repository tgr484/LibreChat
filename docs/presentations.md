# Презентации: инструмент `create_presentation`

Агент собирает презентацию PowerPoint (.pptx) и прикрепляет файл к ответу. Модель передаёт только
содержание (JSON со слайдами), оформление задаёт сервер: минималистичный стиль, формат 16:9,
шрифт Arial, один акцентный цвет. Корпоративного шаблона пока нет; когда он появится, меняется
только `packages/api/src/office/pptx.ts`.

## Как включить

1. Инструмент доступен без настроек в `librechat.yaml`: в конструкторе агента добавить
   «Презентации» в список инструментов.
2. Типичный сценарий с DocHub: у агента включены DocHub и «Презентации»; пользователь просит
   «сделай презентацию по коллекции … про …» — модель собирает материал через `dochub_survey` или
   `dochub_read`, затем один раз вызывает `create_presentation`.
3. Описание инструмента можно заменить без пересборки переменной окружения
   `CREATE_PRESENTATION_DESCRIPTION`.

## Что умеет

| Макет | Содержание |
|---|---|
| титульный | строится автоматически из `title` и `subtitle` |
| `bullets` | заголовок и тезисы (по умолчанию) |
| `section` | разделитель между частями |
| `two_columns` | две колонки с заголовками — для сравнения |
| `table` | таблица до 6 столбцов и 12 строк |

У каждого слайда могут быть заметки докладчика (`notes`) и источники (`sources`,
например `№3 «Испытания турбодетандера», с. 41`) — они печатаются мелким шрифтом внизу слайда.
Длинный текст уменьшается по размеру шрифта, а не вылезает за слайд.

## Где лежит файл

Файл сохраняется в хранилище файлов LibreChat (`fileStrategy`, для `local` — `uploads/<user>/`),
попадает во «Мои файлы» как вложение и скачивается из карточки в чате. Там же — текстовый
предпросмотр слайдов (заголовки и тезисы); он строится встроенным разбором pptx и LibreOffice не
требует. Точная картинка слайдов в предпросмотре возможна только с LibreOffice в образе
(`OFFICE_PREVIEW_LIBREOFFICE=pptx`), это отдельное решение.

## Устройство

- `packages/api/src/office/pptx.ts` — сборка .pptx через `pptxgenjs`;
- `packages/api/src/office/tool.ts` — инструмент: нормализация, сборка, предпросмотр, сохранение;
- `packages/api/src/tools/toolkits/office.ts` — схема и описание для модели;
- `api/server/services/Files/generated.js` — запись файла в хранилище и в базу;
- `api/server/controllers/agents/callbacks.js` — сохранённый файл уходит в чат вложением.
